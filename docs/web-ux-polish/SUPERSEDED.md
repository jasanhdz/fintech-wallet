# Aserciones sustituidas · ronda «UX polish»

Registro exigido por `docs/web-ux-polish/SPEC.md` §5.11 y UX-SC-07. Cada fila es una aserción de las suites heredadas
(`web/e2e-final/t*.spec.ts`, `web/e2e/*.spec.ts`) que fijaba geometría/estilo de fidelidad Stitch o un orden de la API
y que contradice el SPEC de esta ronda; se actualizó al nuevo valor o se retiró. **No** se retiran ni debilitan
aserciones funcionales, de red, de idempotencia, de recuperación, de copy veraz (REC-05) ni de reglas financieras.
